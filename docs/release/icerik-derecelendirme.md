# İçerik Derecelendirmesi (IARC) — Cevap Rehberi

Kategori: **Diğer tüm uygulama türleri**. Bu cevaplarla anket 3 Ekim 2026'da tamamlandı (IARC genel: 12+, ESRB: Teen, PEGI: Ebeveyn rehberliği, USK 16, Brezilya 16).

Genel kural: uygulama kendi içeriğini barındırmaz ama kullanıcının listesindeki her türlü filmi oynatabilir ve TMDB/YouTube'dan afiş, özet ve fragman gösterir.

- **"İçerebilir mi / tasvir edilebilir mi / referans bulunabilir mi"** sorularına → **Evet**
- **"Uygulamanın asıl amacı / odağı mı"** sorularına → **Hayır** (Play yardım sayfasındaki Netflix örneği)

| Bölüm | Cevap |
|---|---|
| Uygulama paketinde derecelendirmeyi etkileyen içerik | Hayır |
| Online içerik (paket dışı içerik gösteriyor mu) | **Evet** |
| Şiddet | Evet; asıl amaç: Hayır; görsel: Evet; kanlı olabilir: Evet; yazılı/sözlü referans: Evet |
| Cinsellik | Evet; asıl amaç: Hayır; görsel: Evet; **pornografik: Hayır**; yazılı/sözlü referans: Evet |
| Dil | Evet; odak: Hayır; hafif küfür: Evet; orta/ağır küfür: Evet; ayrımcı dil: Evet; cinsel içerikli küfür: Evet |
| Kontrole tabi madde | Evet; görsel tasvir: Evet; yazılı/sözlü atıf: Evet |
| Yaş kısıtlamasına tabi ürün tanıtımı/satışı | Hayır |
| Kumar | Hayır |
| Kullanıcılar arası etkileşim / içerik paylaşımı | Hayır |
| Konum paylaşımı | Hayır |
| Dijital ürün satın alma | **Evet** (CineStream PRO) |
| Nakit ödül, hediye kartı, kripto | Hayır |
| Web tarayıcısı veya arama motoru | Hayır |

Not: Yapay zekâ sohbeti kişiden kişiye iletişim değildir; "kullanıcı etkileşimi" sorusu **Hayır** kalır.
